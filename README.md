# Consumer Concepts website

Plain static HTML and CSS for www.omniconsumerconcepts.com. No framework, no build step.

- Pages live in the repo root and small folders (`/insights/`, etc.).
- Shared look is in `assets/site.css`. Brand images are in `assets/img/`.
- `sitemap.xml` and `robots.txt` are edited by hand when a page is added.
- Custom domain: see `CNAME`.

Private repo, separate from the Elroy vault and every other project. See the vault note
"Migrate Website to GitHub Pages" for the plan and the how-to for adding an Insights article.
